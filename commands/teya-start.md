# Teya — первый старт

Покажи пользователю понятную инструкцию. **Не проси открывать и править файлы руками.**

Главное:

0. **Бриф (предпочтительно):** при запросе сайта / брифа используй `/teya-brief` — отправь пустой шаблон `shared/site-brief-template.md`, дождись заполнения. Набор страниц, число статей и ключи берутся **только** из заполненного брифа (не выдумывать; не резать список страниц до 5).

1. **Анкета бизнеса** — пользователь (или сайтостроитель) присылает данные **в чат** (лучше — заполненный бриф). Директор / оркестратор **сам** записывает их в:

```text
teya-memory/site.inv
```

Пользователь `site.inv` **не** заполняет вручную. Если чего-то не хватает — задай короткий список вопросов в чате, получи ответы, допиши файл и продолжай.

Минимум для старта без деплоя: название сайта/компании, краткое описание, телефон (или «без телефона»), email, ниша/услуги, аудитория, **число и список страниц**, **число статей блога**, **ключевые слова** (или «подобрать вместе»), референс дизайна (URL/скрин/описание) и что визуально обязательно повторить. Конкуренты — если есть. Если числа страниц/статей в брифе нет — спроси; не подставляй потолок «5 страниц».

2. Для доступов и секретов (деплой, SMTP, аналитика) скопируй шаблон:

```text
teya-memory/teya.env.example
```

в:

```text
teya-memory/teya.env.local
```

Секреты пользователь может прислать в чат — бот кладёт их в `teya.env.local`. Файл нельзя коммитить и публиковать.

3. Если доступов нет, оставь:

```text
TEYA_DEPLOY_MODE=local-only
TEYA_ALLOW_PUBLISH=no
TEYA_ALLOW_ACTIVATE_THEME=no
```

4. **Ключи / семантика:** не запускай Ядрышко и Wordstat. Список ключевых слов — из заполненного брифа или явного ответа в чате; Директор сам строит URL-карту по списку страниц брифа (см. `rules/manual-keywords.mdc`). Не расширяй ключи «из воздуха».

5. После того как бот заполнил `site.inv` из чата (и при необходимости env.local), можно запускать:

```text
/teya-phase1
```

Не перегружай пользователя техническими деталями. Лучше один раз выдать полный бриф-шаблон (`/teya-brief`). Если отвечают коротко — добери: бизнес, контакты, услуги, регион, **страницы (число+список)**, **статьи (число)**, **ключи**, пример дизайна, ограничения; доступы для деплоя — только если публикация нужна сейчас.
