# Teya — первый старт

Покажи пользователю понятную инструкцию. **Не проси открывать и править файлы руками.**

Главное:

1. **Анкета бизнеса** — пользователь (или сайтостроитель) присылает данные **в чат**. Директор / оркестратор **сам** записывает их в:

```text
teya-memory/site.inv
```

Пользователь `site.inv` **не** заполняет вручную. Если чего-то не хватает — задай короткий список вопросов в чате, получи ответы, допиши файл и продолжай.

Минимум для старта без деплоя: название сайта/компании, краткое описание, телефон, email, ниша/услуги, аудитория, референс дизайна (URL/скрин/описание) и что визуально обязательно повторить. Конкуренты — если есть.

2. Для доступов и секретов (деплой, SMTP, аналитика) скопируй шаблон:

```text
teya-memory/teya.env.example
```

в:

```text
teya-memory/teya.env.local
```

Секреты пользователь может прислать в чат — бот кладёт их в `teya.env.local`. Файл нельзя коммитить и публиковать.

3. Если доступов нет, оставь:

```text
TEYA_DEPLOY_MODE=local-only
TEYA_ALLOW_PUBLISH=no
TEYA_ALLOW_ACTIVATE_THEME=no
```

4. **Ключи / семантика:** не запускай Ядрышко и Wordstat. Список ключевых слов пользователь или сайтостроитель даёт вручную, либо Директор выбирает из брифа/research и сам строит URL-карту (см. `rules/manual-keywords.mdc`).

5. После того как бот заполнил `site.inv` из чата (и при необходимости env.local), можно запускать:

```text
/teya-phase1
```

Не перегружай пользователя техническими деталями. Сначала собери в чате минимальный список: бизнес, контакты, услуги, регион, пример дизайна, что в референсе обязательно повторить визуально, конкуренты; доступы для деплоя — только если публикация нужна сейчас.
