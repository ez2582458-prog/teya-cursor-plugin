# Teya — первый контакт (заглушка-перенаправление)

Этот файл оставлен, чтобы старые ссылки на `docs/00-first-contact.md` не были битыми.
Актуальный порядок первого контакта описан в командах:

1. `/teya-brief` — отправить пользователю пустой бриф (`shared/site-brief-template.md`), дождаться заполнения, сохранить в `teya-memory/00-brief.md`.
2. `/teya-start` — что бот сам заполняет: `teya-memory/site.inv` (из брифа/чата) и при необходимости `teya-memory/teya.env.local` (доступы).
3. `/teya-phase1` — запуск конвейера.

Правила, которые действуют всегда:

- число и список страниц, число статей и ключевые слова берутся только из брифа (`rules/manual-keywords.mdc`), без потолка «5 страниц» и без Ядрышко/Wordstat;
- типовые внутренние страницы — общий шаблон (`shared/shared-inner-page-template.md`);
- никаких выдуманных авторов, отзывов и рейтингов (`shared/quality-anti-haltura.md`, `shared/authors-registry.json`).
